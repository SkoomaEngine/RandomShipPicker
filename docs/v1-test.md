# 1.0.0 实机测试（第 3 轮）

这次测的是正式版。部署时会同时撤下探针，筛选栏里不会再有 RSP 和调试文字，只有一个"随机"按钮。

## 测试步骤（亚服）

1. 进港口，找到筛选栏最右边的"随机"按钮。**截图**。
2. **变暗模式**（"隐藏不符合筛选的船"不勾选）：
   1. 筛选设成 X 级 + 驱逐，连点"随机"10 次左右。每次看两点：选中的船是否在范围内；船坞是否滚到了它。
   2. 把筛选放宽到很多船，比如只选 VIII 级，再点几次。重点看选中的船在画面外时，船坞能不能滚过去。
3. **隐藏模式**（勾选"隐藏不符合筛选的船"）：同第 2 步各点几次。测完切回你平时用的模式。
4. **边界情况**：
   1. 设一个没有船符合的筛选，比如船名搜索填一串乱码。按钮应该变暗，点击无效。
   2. 很快地连点十几下，应该只有一部分点击生效。连点停下后，确认"隐藏不符合筛选的船"仍是你原来的设置。
   3. 只有一艘船符合时，连点几次，应该一直是它。
5. **整体感受**：滚动是否顺畅？有没有闪烁？从点击到滚动的等待能不能接受？
6. 退出游戏，告诉我测完了以及第 2–5 步的观察。日志和截图我自己去读。

## 如果出问题

- 设置没改回来：在船坞筛选设置里把"隐藏不符合筛选的船"改回去。
- 卡住或进不了港口：关掉游戏，删掉 `res_mods\ForgeBlueprints\RSP_RandomShipPicker.xml`，或者运行 `python tools/deploy.py --remove`，再启动游戏即可恢复。
