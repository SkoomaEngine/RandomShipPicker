# Random Ship Picker（随机选船）

《战舰世界》客户端 mod。在港口船坞上方的筛选栏加一个"随机"按钮。点一下，就从符合当前筛选的船里等概率随机选中一艘，船坞也会滚到这艘船。

mod 只有一个纯文本的 ModForge 蓝图（XML 文件）。不含可执行程序和 Python 代码，也不读写任何文件，用记事本打开就能看到它的全部内容。

## 需要

- 《战舰世界》PC 客户端，已在 15.9.0 上测试。
- ModForge 1.0.0 或更高版本。

## 安装

1. 找到游戏目录下编号最大的版本文件夹：`World of Warships\bin\<最大的数字>\`。
2. 把压缩包里的 `res_mods` 文件夹复制进去。复制后文件应位于 `bin\<版本号>\res_mods\ForgeBlueprints\RSP_RandomShipPicker.xml`。
3. 启动游戏，筛选栏最右边会出现"随机"按钮。按钮文字使用游戏自带的翻译，各语言客户端会自动显示对应的文字。

游戏更新后如果出现了新的 `bin\<版本号>` 文件夹，需要再复制一次。如果你的 mod 管理工具会自动迁移 `res_mods`，就不用管。

## 卸载

删掉 `res_mods\ForgeBlueprints\RSP_RandomShipPicker.xml`，重启游戏。ModForge 会自动还原原版界面。

## 使用

- 设好筛选，点"随机"。
- 不管有没有勾选"隐藏不符合筛选的船"，都能用。
- 每次点击都独立抽取，可能连续抽到同一艘。
- 没有船符合筛选时，按钮变暗，点击无效。

## 须知

- **会短暂改动一项设置。** 游戏选船后不会自动滚动船坞，但切换"隐藏不符合筛选的船"时会滚到选中的船。所以每次选中后，本 mod 会切换一下这项设置，约 0.15 秒后改回原值。
  - 正常情况下你察觉不到，设置最终也保持不变。
  - 如果恰好在这一瞬间退出港口或关闭游戏，设置可能停留在切换后的状态，到筛选设置里改回来即可。
  - 设置改回原值之前，再次点击按钮不会生效。
- **只认游戏自带的筛选**，即等级、类型、国家、特殊、稀有度和船名搜索。其他 mod 在船坞里另加的筛选，本 mod 看不到，例如 Port Interface 的"有无舰长、胜率、场次"。
- 只会选你拥有的船。

## 兼容性

- 按钮插在原版港口船坞面板（`ShipsCarouselPanel`）里。其余逻辑都在本 mod 自己的定义中，统一使用 `RSP_` 前缀。
- 不改动 Unbound 2 船坞，Aslain 的 Port Interface 等船坞类 mod 可以照常使用。
- 如果还装了别的随机选船按钮（例如 Port Interface 的"随机战舰选择器"组件），建议只保留一个。
