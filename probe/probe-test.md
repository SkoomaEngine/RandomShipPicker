# 探针 RSP_Probe：测试说明

当前版本是 0.2.0（第 2 轮）。探针只用来验证技术问题，不是正式版，测完就删掉。

## 第 2 轮要验证什么

第 1 轮发现了两个问题：

- 船坞在"变暗显示"模式下，游戏自带的筛选结果列表不更新，所以 ROLL 会选到筛选范围外的船。
- 选船后船坞不会自动滚到那艘船。

第 2 轮测试两种自建的筛选列表（ROLL、ROLL2），再加五种让船坞滚动的办法（S1–S5）。

## 按钮

点筛选栏最右边的 RSP，会出现下面这些按钮和一块黑底调试文字。再点一次 RSP 就收起。

| 按钮 | 作用 |
|---|---|
| ROLL | 用办法 A 的列表随机选船 |
| ROLL2 | 用办法 B 的列表随机选船 |
| S1 | 直接给船坞发"滚到第 N 艘"的指令 |
| S2 | 把"隐藏/变暗"切换一下再切回来，大约 0.15 秒 |
| S3 | 在船名搜索里填一个搜不到的词，再还原，大约 0.15 秒 |
| S4 | 把当前的船名搜索原样再提交一次 |
| S5 | 把当前的"隐藏/变暗"设置原样再提交一次 |

## 调试文字

| 行 | 内容 | 含义 |
|---|---|---|
| 1 | `RSP probe 0.2.0   hidden=…   sorted=M` | hidden：是否"隐藏不符合筛选的船"。M：船总数 |
| 2 | `game=…   live=…   prefix=…` | 三种方式数出来的"符合筛选的船数"。game 是游戏自带的（第 1 轮已知在变暗模式下不准），live 是办法 A，prefix 是办法 B |
| 3 | `ROLL x次数   src=…   idx=…   match=…` | src 表示用的是哪个列表。match=true 表示选中的船确实符合筛选 |
| 4 | `pick ID 船名` | 选中的船 |
| 5 | `current ID   carouselIdx=…` | 当前选中的船，和它在船坞里的位置 |
| 6 | `test S? x次数   search=[…]` | 最后按的是哪个 S 按钮，以及当前的船名搜索内容 |

## 测试步骤（亚服，第 1–6 步用默认的"变暗显示"）

"变暗显示"指"隐藏不符合筛选的船"**不勾选**，这是游戏的默认设置，不用另外调。只有第 7 步要临时勾上它。

船坞视图用你平时的 Port Interface"紧凑卷轴视图"就行，不用换成游戏原生视图。

1. 进港口，点 RSP。
2. **列表测试**：筛选设成和上次一样的"X 级 + 驱逐"，正确数字应为 25。看第 2 行的 live 和 prefix 是不是 25。**截图**。
3. 换一个筛选，比如再加一个国家，或者改成 IX 级，看 live 和 prefix 会不会跟着变。**截图**。
4. 连点 ROLL 大约 10 次，再连点 ROLL2 大约 10 次。每次留意两点：选中的船是否在筛选范围内，match 是否一直是 true。各**截图**一张。
5. **卡顿测试**：RSP 打开时，改筛选会不会比平时卡？
6. **滚动测试**：先点"全部重置"清空筛选。只有 25 艘船时整个列表都在画面里，看不出船坞有没有滚动。

   之后每个 S 按钮单独测，步骤相同。先按 ROLL，直到选中的船不在当前船坞画面里；然后按 S1，看船坞有没有滚到选中的船。再 ROLL 到一艘看不见的船，按 S2……依次测到 S5。每个按钮记下：滚了 / 没滚 / 有闪烁。
7. 在筛选设置里切到"隐藏不符合筛选的船"，按几次 ROLL 和 ROLL2，再把第 6 步里有效的 S 按钮试一次。**截图**。然后切回你平时用的模式。
8. 退出游戏，告诉我测完了，以及第 5、6 步的观察。日志和截图我自己去读。截图照常按 Steam 的 F12 就行，我能找到。

## 注意

- **S2、S3 会临时改你的设置**，大约 0.15 秒后自动还原：S2 改"隐藏/变暗"，S3 改船名搜索。如果测试结束后发现设置没还原：
  - 显示模式：在船坞筛选设置里切回来。
  - 船名搜索：点"全部重置"，或者清空搜索框。
- **卡住或进不了港口**：关掉游戏，删掉 `res_mods\ForgeBlueprints\RSP_Probe.xml`，或者运行 `python tools/deploy.py --remove`，再启动游戏即可恢复。

## 第 1 轮（0.1.0）结论

- 变暗显示模式下，游戏自带的 `filtered.sorted` 不更新，停留在上一次的值；每艘船的 `carouselFilter.isFiltered` 两种模式下都实时更新。
- 变暗显示模式下，`sorted` 把符合筛选的船排在最前面。
- `math.randomfloor` 质量没问题；`selectShip` 能选船，但船坞不会滚过去。

## 第 2 轮（0.2.0）结论

- 列表：ROLL2 的列表（`sorted` 的前缀）始终准确；ROLL 的列表在变暗模式下会混入不符合筛选的船。
- 滚动：只有 S2（切换"隐藏不符合筛选的船"再切回）和 S3（改搜索词再还原）能让船坞滚到选中的船；S3 在隐藏模式下会先闪出"没有符合条件的船"。正式版采用 S2。
